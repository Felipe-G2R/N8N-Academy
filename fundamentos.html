Fundamentos de Programação no N8N

Domine JavaScript, JSON e HTTP/APIs para alcançar produtividade de 100% na automação inteligente

Voltar ao Início

A Jornada para o Domínio da Automação Inteligente

A jornada para se tornar um mestre na automação com o n8n, especialmente na criação de agentes de inteligência artificial sofisticados, transcende a mera habilidade de conectar nós visualmente. Embora a interface intuitiva do n8n permita a construção rápida de fluxos de trabalho, o verdadeiro poder e a produtividade de 100% residem na profunda compreensão dos alicerces de programação que sustentam a plataforma.

Tratar o n8n como uma ferramenta puramente "no-code" é limitar seu potencial; reconhecê-lo como um ambiente "low-code" que capacita desenvolvedores e analistas a implementar lógicas complexas, customizar comportamentos e integrar-se a uma infinidade de serviços é o que separa os amadores dos profissionais.

Este guia serve como um mapa completo para desvendar os conceitos fundamentais de JavaScript, JSON e HTTP/APIs que são absolutamente cruciais para dominar a lógica de automação no n8n.

JavaScript

O Motor da Lógica e da Customização

JavaScript é a espinha dorsal que permite a lógica programacional avançada dentro do ecossistema do n8n. É a linguagem que dá vida ao Code Node, um dos componentes mais poderosos da plataforma, que serve como uma saída de emergência para implementar funcionalidades customizadas que não estão disponíveis nos nós pré-construídos.

Fundamentos Essenciais

Variáveis & Tipos

Declaração com let e const. Tipos primitivos: string, number, boolean, null, undefined.

Arrays & Objetos

Listas de itens e coleções de pares chave-valor. Base do fluxo de dados no n8n.

Manipulação de Strings

Métodos como toUpperCase(), toLowerCase(), slice(), split() e join().

Controle de Fluxo

Estruturas if/else, switch para tomada de decisão e lógicas condicionais.

Conceitos Avançados

Programação Assíncrona: Muitas operações em automações não acontecem instantaneamente. JavaScript lida com isso através de Promises e da sintaxe async/await.

async function fetchData() {
  const response = await fetch('https://api.example.com/data');
  const data = await response.json();
  return data;
}

Code Node no N8N

O Code Node permite que você escreva JavaScript para processar dados recebidos de nós anteriores. Variáveis especiais disponíveis:

  • $input.all() - Obtém array com todos os itens de entrada
  • $input.first() - Obtém apenas o primeiro item
  • $input.item(index) - Obtém item específico
  • $moment - Para manipulação de datas
  • $binary - Para lidar com dados binários
// Exemplo: Processar todos os itens
const items = $input.all();
return items.map(item => ({
  json: {
    ...item.json,
    processed: true,
    timestamp: new Date().toISOString()
  }
}));

TypeScript para Custom Nodes

Para customização máxima, TypeScript é usado para criar custom nodes. TypeScript adiciona tipagem estática, tornando o código mais seguro, autoexplicativo e fácil de manter.

JSON

A Língua Franca da Troca de Dados

JSON (JavaScript Object Notation) é a língua franca do n8n - o meio fundamental pelo qual toda a informação flui entre os nós. Compreender JSON não é negociável, é absolutamente essencial.

Estrutura Fundamental

Objetos

Coleção não ordenada de pares chave/valor delimitada por { }

{"nome": "João", "idade": 30}

Arrays

Lista ordenada de valores delimitada por [ ]

[{"nome": "João"}, {"nome": "Maria"}]

Tipos de Dados Suportados

  • String: Texto entre aspas duplas: "exemplo"
  • Number: Inteiros ou decimais: 42, 3.14
  • Boolean: Verdadeiro ou falso: true, false
  • Null: Ausência intencional de valor: null
  • Object: Objeto aninhado
  • Array: Lista de valores

JSON no N8N

A entrada e saída de quase todos os nós no n8n são estruturadas em JSON. Para mapear dados entre nós, você usa expressões dinâmicas:

// Acessar campo simples
{{$json.nome}}

// Acessar objeto aninhado
{{$json.user.email}}

// Acessar item de array
{{$json.items[0].name}}

Exemplo Prático

Cenário: Webhook recebe dados de pedido de e-commerce
{
  "pedido_id": "12345",
  "cliente": {
    "nome": "Ana Souza",
    "email": "ana.souza@email.com"
  },
  "itens": [
    {"produto_id": "A987", "quantidade": 2},
    {"produto_id": "B654", "quantidade": 1}
  ],
  "total": 150.75
}

Mapeamento para Google Sheets:

  • ID do Pedido: {{$json.pedido_id}}
  • Nome do Cliente: {{$json.cliente.nome}}
  • Email: {{$json.cliente.email}}
  • Total: {{$json.total}}

HTTP & APIs

Conectando seu Agente ao Mundo Digital

Para que um agente de IA construído no n8n possa verdadeiramente "agir" e interagir com o mundo, ele precisa se comunicar com uma infinidade de serviços externos. Essa comunicação é realizada através de APIs (Application Programming Interfaces), e o protocolo que rege essa comunicação na web é o HTTP.

O que são APIs?

Uma API é um contrato que permite que diferentes aplicações se comuniquem. É como um garçom em um restaurante: você (o cliente) faz seu pedido seguindo o menu (a documentação da API), e o garçom traz seu prato (a resposta da API).

Métodos HTTP

GET

Recuperar ou ler dados de um recurso

POST

Criar um novo recurso

PUT/PATCH

Atualizar recurso existente

DELETE

Remover um recurso

Componentes de uma Requisição HTTP

  • URL/Endpoint: O endereço do recurso
  • Headers: Metadados (Content-Type, Authorization)
  • Body: Dados enviados (POST, PUT, PATCH)

Códigos de Status HTTP

  • 200 OK - Sucesso
  • 201 Created - Recurso criado com sucesso
  • 400 Bad Request - Requisição malformada
  • 401 Unauthorized - Falha de autenticação
  • 404 Not Found - Recurso não existe
  • 500 Internal Server Error - Erro no servidor

APIs RESTful

REST (Representational State Transfer) é um estilo arquitetural para APIs. Características principais:

  • Cliente-Servidor: Separação clara de responsabilidades
  • Stateless: Cada requisição contém todas as informações necessárias
  • Cacheável: Respostas marcadas para reutilização
  • Interface Uniforme: Operações padronizadas (GET, POST, PUT, DELETE)

Autenticação

API Key

Chave única incluída em headers ou parâmetros

X-API-Key: SUA_CHAVE_AQUI

OAuth 2.0

Token de acesso via fluxo de consentimento

Authorization: Bearer <TOKEN>

Exemplo de Requisição

POST /api/v1/data
Content-Type: application/json
Authorization: Bearer {{token}}

{
  "query": "search term",
  "limit": 10
}

O n8n possui um nó HTTP Request que permite configurar todos esses componentes visualmente, e um sistema de Credentials para gerenciar autenticação de forma segura.
